# Security Policy & Disclosure

This project is open source under the Apache-2.0 license. We take security seriously and have designed the application architecture to ensure safe public deployment and GitHub hosting.

---

## 🛡️ Security Architecture & Protections

### 1. API Key Isolation (Google Gemini)
- **Zero Browser Exposure**: The Gemini API key (`GEMINI_API_KEY`) is strictly accessed on the backend server (`server.ts`). It is never bundled, compiled into static client assets, or exposed to the browser.
- **No Client Secrets**: Client-side code never receives, stores, or handles raw API credentials.
- **Server-Sent Events (SSE) Proxy**: All communications with the `@google/genai` SDK pass through an authenticated server-side streaming proxy endpoint (`/api/gemini/stream`).

### 2. Request Sanitization & Rate Limits
- **Input Clamping**: Prompts are length-sanitized and bounded to prevent resource exhaustion.
- **Bounded Token Parameters**: Output tokens are strictly capped to safe operational limits (max 512 tokens).
- **Masked Errors**: Error responses generated by backend calls are sanitized before being transmitted to the client, preventing stack traces, system paths, or environment data leakage.

### 3. Standalone Simulation Mode
- When deployed in a public environment without a configured API key, the application seamlessly operates in an offline token simulation mode. Public users on GitHub can test and explore all interactive features without entering any secrets.

---

## 📋 Reporting a Vulnerability

If you discover a security vulnerability or sensitive information exposure within this repository, please follow these steps:

1. **Do NOT open a public GitHub issue.**
2. Send an advisory report with technical details directly to the maintainers or via GitHub Private Vulnerability Reporting if enabled on the repository.
3. Include:
   - Type of vulnerability (e.g., secret leakage, XSS, SSRF)
   - Step-by-step instructions to reproduce
   - Potential impact
4. We aim to acknowledge reports within **48 hours** and provide a patch or mitigation timeline.
